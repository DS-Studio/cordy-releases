# 安装 Cordy 浏览器扩展

English version: [install-chrome.md](install-chrome.md)

## 从 Chrome 应用商店安装

这是安装 Cordy 浏览器扩展的受支持方式：

**https://chromewebstore.google.com/detail/cordy/kdpfbabcgdgcddadcdacejaaepgkajih**

商店上架的就是当前版本。通过应用商店安装可以获得自动更新，也不会有 Chrome
的安全警告——除非有特别原因，否则请使用这种方式。

## 本仓库没有扩展的下载

**本仓库当前没有发布 Cordy 浏览器扩展的任何构建包。** 上方的 Chrome 应用商店是
唯一的获取渠道。本页保留，是因为扩展的更新日志在本仓库维护，也因为"那个 .zip 在哪"
这个问题下面有真实的答案。

如果将来的 Release 附带 `.zip`，它会是**核对/审计用的校验产物，不是另一条安装
路径**——即提交给 Chrome 应用商店审核的那个具体包的副本，供核对使用。

何况 Chrome 本来就不允许普通用户从任意来源安装打包好的扩展。从 Windows 上的
Chrome 33、macOS 上的 Chrome 44 开始，除非你自己开启开发者模式，否则 Chrome 只
允许通过应用商店安装扩展。这样的 zip 无法通过双击或拖拽装入 Chrome。

## 开发者模式：适合确实需要的人

仅当你通过其他途径拿到了扩展包时才适用——本仓库今天没有可下载的内容。
以"加载已解压的扩展程序"方式安装：

1. 对照随包发布的校验和核对它的 SHA-256——见 [verify.md](verify.md)（英文）。
2. **解压**到一个你会保留的文件夹。Chrome 每次启动都会从这个文件夹加载，
   安装完成后不要删除它。
4. 打开 `chrome://extensions`。
5. 打开右上角的 **"开发者模式"** 开关。
6. 点击 **"加载已解压的扩展程序"**。
7. 选择解压后的文件夹。

### 这样做需要付出的代价

- **没有自动更新。** 每次有新版本都要重复上面这些步骤。
- **持续显示的警告。** 只要还有任何以开发者模式加载的扩展，Chrome 每次启动都会
  显示"停用开发者模式扩展程序"的提示条。

只有在理解并接受这两点之后，才使用这种方式。
